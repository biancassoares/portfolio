# Portfolio

Meu portfólio pessoal desenvolvido para apresentar meus projetos, tecnologias e evolução como desenvolvedora.

## ✨ Funcionalidades

- Layout responsivo
- Versão em Português e Inglês
- Navegação entre seções
- Apresentação de projetos
- Links para GitHub, LinkedIn e contato

## 🛠️ Tecnologias

- HTML
- CSS
- JavaScript

## 🎨 Sobre o projeto

O projeto foi desenvolvido com foco em um visual clean, responsivo e com alguns detalhes que representam minha personalidade.

Meu principal foco de estudos é desenvolvimento backend com Java e Spring Boot, mas aproveitei a criação deste portfólio como uma oportunidade para também praticar e evoluir minhas habilidades em frontend com HTML, CSS e JavaScript.
